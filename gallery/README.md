# Figurer Gallery

This directory will hold rendered reference figures for plotting patterns that have proven useful in real projects.

The gallery is intentionally **earned from real work** rather than populated with dozens of synthetic examples up front.

Initial candidates from current computational-biology workflows:

- clean categorical UMAP / embedding;
- continuous program-score embedding;
- annotation-heavy program × reference-module heatmap;
- enrichment bubble plot;
- patient × program summary heatmap;
- spatial state map over histology;
- spatial adjacency/effect matrix;
- multi-panel spatial + quantitative evidence figure;
- grouped patient-level distribution figure.

When adding a gallery item, include the code/configuration that produced it. The rendered figure should be treated as the visual reference, not only the script.
